# OutageIQ Backend

This backend serves the isolated OutageIQ duplicate inside the NOCSquad workspace.

It provides demo endpoints for:

- `/api/health`
- `/api/login`
- `/api/overview`
- `/api/outages`
- `/api/regions`
- `/api/analytics`
- `/api/export`

The service uses seeded outage data only and does not modify the existing analytics pipeline, raw files, or tests.
